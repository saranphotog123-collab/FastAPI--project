# Student Management API Design

## API Name
Student Management API

## Description
This API is used to manage student records.

## Entity
Student

## Fields
- id
- name
- age
- department
- email

## Endpoints

### GET /students
Get all students.

### GET /students/{id}
Get a student by ID.

### POST /students
Create a new student.

### PUT /students/{id}
Update a student.

### DELETE /students/{id}
Delete a student.
